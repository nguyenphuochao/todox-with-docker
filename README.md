* How to setup run source by docker
1. download docker
2. cd todox-with-docker/
3. cd backend/
4. copy .env.example to .env
5. cd ../todox-with-docker/
6. run CMD: docker compose up

* How to setup run source by node
1. download nodejs
2. cd todox-with-docker
3. cd backend
    3.1 copy .env.example to .env
    3.2 npm install
    3.3 npm run dev
4. cd frontend
    4.1 npm install
    4.2 npm run dev
